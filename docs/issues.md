# 已知限制

- 0.7 的 Ubuntu 捏合在 GTK 层转交给 PDF，触控板惯性与页面边缘单独处理；已在真实 WebKitGTK 中注入原生 GDK 手势验证，尚待用户的 24.04.3 LTS 笔记本复测。不同触控板驱动与 Wayland / X11 组合的手感可能不同。
- Android 0.7 支持 Android 8+ 的 ARM64 / x86_64，暂不提供 32 位包或移动 OCR。首次打开默认专注阅读，外接键鼠仍可使用。系统选中的 PDF 会复制到应用私有目录（单份不超过 512 MB），卸载应用会删除副本和状态，不修改外部原文件。APK 已签名，更新需保留本工程的签名密钥。
- Android 12 模拟器已验证选取文件、原生渲染、键盘翻页和区域截图；原生 PNG 保存完成与实际手机手势仍待复测。浏览器手机布局和双触点测试已通过。
- 0.6 桌面按当前展开的文件、阅读框和纸叠计算可平移范围，外围保留余量，不保留没有实体的历史浏览区块。文件仍能拖到任意位置，在视野边缘拖住会继续跟随。新文件按当前视野放置，完整文件组恢复和标签原位展开仍保留世界坐标。
- OCR、主题及启动选项已统一为应用内主题菜单；文件打开 / 保存窗口继续使用系统文件对话框。

- 0.5.4 的纸叠显示开关不会自动适配正文，适合整页 / 宽度仍由独立按钮控制。桌面纸叠使用自由世界坐标，框内和专注模式保留区域约束；整份文件的手动搬动与正文滚动分别处理。隐藏纸叠不丢失自定义位置，查看全部包含显示中的自由纸叠。

- 0.5.3 的目录按钮位于每份文件自身左上角，选中或悬停时显示；完全被其他纸张遮住的按钮遵循桌面遮挡关系，可点击露出的纸面将文件置前。长页滚动保留可见按钮，框选期间临时让出该区域。

- 0.5.2 的目录属于当前文件，切换文件或点击空白桌面会收起，展开状态不跨重启保存；边缘空间不足时目录覆盖文件左缘以保持可见。桌面禁用原生文字 / 图片选区，OCR 输出与实际输入框仍可正常选择文字。

- 0.5 支持可选的上次文件组自动打开，默认关闭；摆放、收纳、阅读框、桌面视野与阅读位置保存在本机，不跨设备同步。明确指定的启动 PDF 优先。丢失或改名的文件不会自动搜索迁移，会保留记录并提示。
- 每份文档可选散纸或阅读框。散纸通过自身移动实现页内滚动；框内使用独立裁切视口，边界后才翻页。0.5.1 起前后纸叠的桌面位置独立保存，正文滚动或缩放不会带走它们；手动搬动整份文件和桌面整体变换仍作用于纸叠。临时笔和框选只操作选中文件。桌面倍率、正文宽度、框尺寸和专注倍率分开保存。锚点恢复当前阅读表面的页码与比例，不恢复历史 camera 或全部摆放。
- 侧栏在小窗口下可滚动，所有按钮有悬停名称。当前窗口三键为自绘按钮，已核对最小化、最大化 / 还原与保存后关闭；未宣称原生 Windows 11 最大化按钮的悬停 Snap 菜单兼容性。
- 背景导入接受 25MB 内 JPEG / PNG / WebP，保存最长边 2560 的 JPEG 副本；不会保存原文件的无损像素、动画或透明通道。图片不透明度针对应用内背景图片，不是整个原生窗口的穿透透明度。

- 支持 Windows x64、Ubuntu amd64 与 Android ARM64 / x86_64；Ubuntu 22.04、24.04 已通过独立环境安装 / 卸载和真实 WebKitGTK / PDFium / OCR 联合验证。26.04 未单独验收；Linux 的 Wayland、系统文件选择器及剪贴板还需桌面验证。尚无 macOS 或 Linux ARM64 构建。
- 便携版依赖系统 WebView2 Runtime，DLL 与许可证须随整个文件夹保留。安装器配置提供 WebView2 下载引导，干净系统还需验证。
- PDF 以原生渲染图片呈现，没有可选取的前端文本层；复制正文目前通过区域 OCR。原生保留页文本读取能力。
- Windows OCR 识别质量取决于语言组件和系统引擎；英文在默认中文引擎下可能出现个别误识别。未带入可选 PP-OCR / MNN / 模型。
- Ubuntu OCR 使用 apt 安装的 Tesseract 和中英文数据，识别质量与 Windows 引擎不同；首次安装系统依赖需要网络，后续 OCR 可离线工作。
- 100% 对应 CRH 的 baseScale=2 逻辑尺寸约定，不等同于物理打印比例。800% 时位图受 16M 像素预算限制，放大显示可能比中等倍率柔和。
- 状态按规范路径识别。文件移动 / 改名视为新文档；同一路径替换了 PDF 时只夹紧页码，不跟踪章节语义。
- 普通关闭 / 重开恢复页码、缩放与阅读形式，不恢复全部页内滚动；锚点才精确保存双轴比例。预览内部滚动不跨重启保存。
- 状态损坏或未来版本会保护原文件并暂停该文档写入。修复方式：先备份应用数据目录中对应 JSON，再由用户移走损坏文件后重开；界面没有隐式覆盖 / 导入操作。
- 窗口正常关闭会等待状态写入，强制结束进程或断电可能丢失最后 350ms 尚未提交的进度；已落盘文件使用原子替换。
- PNG 复制已在实际 WebView2 验证；其他机器受到系统限制时会提示，仍可另存 PNG。OCR 结果只在当前捕获面板，不永久保存历史。
- Windows release 未做代码签名，Ubuntu 包提供 SHA-256，Android APK 使用项目保留的密钥签名。没有迁移原 CRH 状态、永久标注、全文搜索、书库、同步、登录、AI 或插件入口。
- 本机会话的 computer-use 窗口画面捕获超时，后通过显式配置的隔离 QA 构建完成真实 WebView2 / 原生 IPC 联合验证。它与普通发布配置只在测试标识 / devtools 上不同；跨显示器手感、真实大 PDF 和安装器人工验收仍待完成。

用户真实 PDF 和长时间阅读仍是最终手感验收，不以合成测试替代。
