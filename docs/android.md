# Android 0.7

安装 `release/Lightning_0.7.0_android.apk`。需要 Android 8.0（API 26）或更新版本，包含 ARM64 和 x86_64；未提供 32 位 Android 版本。

首次进入专注阅读，点左下角菜单中的文件夹打开 PDF。通过系统文件选择器选择的文件会复制到应用私有存储，以便 Android 重启或撤销临时文件授权后仍能恢复阅读。不修改外部原文件。单份导入上限 512 MB；卸载应用会移除私有副本和阅读状态，原文件仍保留。

- 阅读模式下单指拖动滚动当前页；到边缘后继续滑动约一指宽，松手翻页。下一页贴页首，上一页贴页尾；一次滑动最多翻一页。
- 双指捏合只缩放手势开始时指向的 PDF，纸叠和应用界面尺寸独立。缩放保持手指下的正文位置，缩放后松开手指不会误翻页。
- 激光笔 / 荧光笔模式下单指临时书写，双指可转入缩放。临时笔迹不写回 PDF。
- 菜单可切换自由桌面；拖文件的标题把手移动纸张，拖空白处移动视野。手机下工具在底部，可横向滑动查看更多；平板横屏使用侧栏。
- 外接鼠标的滚轮、Ctrl+滚轮以及键盘 PageUp / PageDown、方向键、缩放快捷键继续可用。触屏手势与鼠标操作分别识别。
- 保留区域截图和保存 PNG；Android 本版不提供 OCR。桌面 Windows / Ubuntu 的 OCR 仍保留。

签名密钥保存在工程 `.android-signing/`，不要随 APK 分发。后续版本应保留并备份这一目录，否则不同签名的 APK 不能覆盖安装。

构建环境使用 Linux / WSL、Docker、curl 和 Python 3，在工程根目录运行 `bash scripts/release-android.sh`。SDK、NDK、Rust 和 Gradle 均在隔离构建环境准备，最终用户不需要安装这些工具。构建依赖缓存只监听本机回环地址，访问固定的上游公开仓库，不进入应用安装包。
