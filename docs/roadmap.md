# 路线图

## Ubuntu 安装包已实现

Ubuntu 22.04 基线的 amd64 `.deb`、Linux PDFium 及资源目录定位、PDF 桌面打开入口、中英文离线 Tesseract OCR、可复用的隔离构建脚本。通过干净环境安装 / 卸载和 9 项真实 WebKitGTK / 原生 IPC 检查。后续补充 24.04 / 26.04 及 GNOME / Wayland 实机体验。

## 0.5 已实现

标签原位收纳与展开；每文件独立选择散纸或可移动、可调宽高的阅读框，正文在框内裁切并按框内边缘翻页。工作区保存文件组、标签顺序、收纳、当前目标、纸张与框的几何、桌面视野以及框内 / 专注阅读比例。可选启动时重开上次文件组，恢复上次阅读位置或从第 1 页开始；缺失文件继续恢复其余文件并保留记录。

## 0.4.1 已实现

Ctrl+滚轮只缩放鼠标下的文档，鼠标处正文位置保持；其他文件与桌面倍率不变。默认 / 手动纸叠尺寸与正文宽高分开，缩小正文不会压缩较大的预览。连续同页缩放保留滚轮目标 DOM，跨文件缩放在异步渲染前固定身份。

## 0.4 已实现

单行文件标签与窗口三键、应用折叠图标菜单、默认展开的阅读图标侧栏、暂时状态提示。无界桌面保留纸张叠放，鼠标下方的大纸张先滚动后翻页，前进 / 后退分别贴可视上缘 / 下缘；文档身份在异步导航前固定。画笔与框选按实际阅读区域裁切，桌面锚点保存可视比例，混合页面尺寸按实际宽度匹配清晰位图。

## 0.3 已实现

文档从浮动窗口改成直接铺在桌面上的真实纸张，支持拖纸面、实际遮挡与置顶、任意方向世界坐标、camera 平移与鼠标定点缩放、查看全部、真实长宽比缩放、各文件自己的前后页纸叠。桌面放大后自动补充清晰位图，专注阅读保留原滚动语义，旧版布局可迁移。

## 0.2 已实现

自由桌面多文档同屏、纸张移动与独立缩放、重叠置前、独立阅读表面、桌面平移 / 整体缩放、专注模式切换、布局记忆。新增 Material 圆角设计、主题色自定义、浅色 / 深色 / 跟随系统、本地背景图与不透明度、预览取消和外观持久化。

后续优先根据用户多文件对照的实际手感调整默认纸张大小和整理方式；不默认引入书库或云端功能。

## 0.1 已实现

独立原生 PDF 链路、文档状态、单页导航 / 适配、多标签 / 目录、有界调度、双向纸叠与几何、阅读篇幅、一次性锚点、临时笔迹、可配置快捷键、原生区域 PNG / 系统 OCR、本地输出面板。

## 当前交付收尾

独立便携目录、ZIP 和 NSIS 安装包随版本交付；76 组浏览器回归、20 组真实 WebView2 / 原生 IPC 联合验证通过。阅读框、标签收纳、文件组重开、Ctrl+滚轮、窗口三键、正常退出、重启锚点和主题背景恢复已核对。仍需用户实际 PDF 的长时间阅读与干净机器安装验收。原项目保持独立，不改用户文件。

## 优先后续

1. 用用户实际 PDF 长时间验证翻页、滚轮边界、不同 DPI 与纸叠对照手感。
2. 干净 Windows 环境验证 NSIS / WebView2 安装、卸载与文件关联方案，再决定签名和发布渠道。
3. 根据实际压力测试调整图片解码 / GPU 内存与超大扫描页的分辨率策略。
4. 若用户确实需要，提供显式、只读的 CRH 阅读状态导入；必须独立实现，不默认扫描或修改 `.crh`。

首版保持阅读聚焦。书库、云同步、永久批注、全文检索、AI 等扩展需另行明确需求。
