Lightning 0.6.0 · Windows x64

双击 Lightning.exe，展开左侧菜单后点文件夹图标打开 PDF，也可 Ctrl+O 或拖放文件。
顶部只保留文件标签和窗口三键；阅读工具默认在左侧展开，悬停图标查看名称。
新拖入 / 打开的文件出现在当前视野内，不需要返回原点寻找。
桌面平移限制在展开文件和纸叠外围的一圈区域；把文件拖到视野边缘会继续扩展，文件可以搬到任意位置。
OCR、界面主题及启动恢复选项统一使用圆角主题菜单；方向键选择，Enter 确认，Esc 取消。
纸叠用菜单中的单个图标按钮直接显示 / 隐藏，无下拉弹框，不改变正文的位置、大小和缩放。
桌面纸叠可自由拖出纸张范围，移动整份文件时保持相对位置；查看全部会包含这些纸叠。
点击每份文件自身左上角的目录按钮，在它左侧展开目录，再点收起；左侧工具栏不再放目录入口。
目录随文件移动；切换文件、收纳或点击空白桌面时自动收起。
桌面文字和图片不会被原生选中；页码输入、OCR 文字编辑及复制照常可用。
桌面文件点击标签会动画收进标签，再次点击在原位展开；动画中点击可反向，× 才是关闭。
选中文件，点侧栏的阅读框图标，可独立切换散纸或框内阅读。
阅读框拖标题移动，右下角调整宽高；滚轮与翻页按框内边缘工作。
应用菜单「启动与恢复」可选重开上次文件组，并选择继续上次位置或从第 1 页开始。
文件摆放、收纳、纸张大小、阅读框和纸叠会记住；自动重开默认关闭。
默认进入无界桌面：多份 PDF 如同散放的纸张，可任意摆放和重叠。
直接拖动纸面移动，拖右下角等比例缩放；纸张旁边可单独翻页。
鼠标在哪份文件上滚动就操作哪份；大纸张先在可视区域内滚动，边界后才翻页。
下一页从可视上缘开始，上一页贴可视下缘；不会带动其他文件。
正文滚动、翻页或缩放时，前后纸叠留在独立的桌面位置；手动搬动整份文件时一起移动。
点选纸面后，侧栏工具操作该文档。应用菜单可切换专注阅读与无界桌面。
拖动空白处、中键或按住空格拖动可平移；空白处滚轮缩放桌面。
侧栏下方可整理纸张、查看全部、整体缩放；工具较多时可在侧栏内滚动。
应用菜单中的外观图标可自定义主题色、背景图片与不透明度；支持浅色、深色与跟随系统。
外观实时预览，取消会还原；保存后重启恢复。背景会保存压缩副本，不修改原图。
可用附带的 reading-sample.pdf 检查翻页、目录、纸叠和捕获。
请保留同目录的 pdfium.dll 与 licenses；整个文件夹可以移动。

Ctrl+O 打开 · Ctrl+W 关闭当前文档 · Ctrl+S 保存进度
← / PageUp 上一页（页尾） · → / PageDown 下一页（页首）
桌面：Ctrl+滚轮缩放鼠标下的 PDF，纸叠大小不变 · + / - 缩放纸张 · 0 恢复纸张 100%
专注：Ctrl+滚轮缩放 PDF · 放大后页内滚动，边界翻页
Ctrl+G 框选 PDF 区域 · Esc 取消框选 / 清除并退出临时画笔

纸叠：上方把手移动，右下角调整大小。「记」保存阅读篇幅，长按纸叠临时展开，松开复原。
锚点：设置后可以自由查阅，再点击返回；成功返回后清除这次锚点。
画笔：按住一直显示，松开后整组消退；完全消失前续写会重新计时。

状态位于 %APPDATA%\com.lightning.pdfreader\reading。
不会修改 PDF，不写入 CRH 项目，不需要 Node / Python / AI 服务。
本版本需要 Windows WebView2 Runtime；当前 Windows 机器已验证。
如果系统缺少 WebView2，可从微软官方页面安装后再运行：
https://developer.microsoft.com/microsoft-edge/webview2/
Windows OCR 使用系统语言包，识别精度由系统引擎决定。
