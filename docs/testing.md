## 复现

```powershell
pnpm test
pnpm test:native
pnpm test:webview
pnpm release
```

测试不会调用聊天 / Agent / 笔记 mock，不引用原项目 node_modules 或 target。原生冒烟直接调用引擎与存储，与浏览器模拟分开报告。首轮 Rust 在线索引访问因本机 TLS 凭据环境失败，使用本机已有 Cargo 缓存完成独立离线编译；没有依赖原工程构建产物。

便携版中的 `SHA256.txt` 记录 EXE 与 PDFium 校验值；ZIP 包含完整运行目录。安装包已解包核对，内部 EXE / DLL 与便携版哈希一致，许可证齐全；没有自动执行安装。

Windows 原生窗口自动化采用 computer-use 技能，画面捕获失败后按技能停止重复输入。首轮仅设置环境变量的 CDP 连接未启动端口，检查子进程参数后改用明确的 QA 窗口配置并通过联合验证。`pnpm test:webview` 会构建测试副本，结束后恢复普通构建目标；需要本机可运行的 WebView2 与桌面进程权限。这一记录与浏览器模拟、引擎冒烟分开，不把它们混称为正式包的全场景人工验收。
