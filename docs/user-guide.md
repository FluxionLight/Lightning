# 操作指南

## 标签栏与侧边栏（0.4）

顶部只保留文件标签和右上角最小化、最大化 / 还原、关闭三键。拖动标签之间的空白可移动窗口，双击可最大化或还原。关闭窗口前仍会等待阅读状态保存；失败时可取消退出或放弃本次未保存状态。

左上菜单图标点击展开应用菜单，提供打开文件、桌面 / 专注模式、纸叠显示开关、外观、快捷键、画笔设置、启动与恢复及帮助。使用后自动收起，点外部或按 Esc 也可收起。按钮使用线条图标，悬停可查看名称。

0.5.4 起，纸叠使用单个按钮切换，选中表示已显示；再次点击隐藏，不再弹出下拉菜单。显示或隐藏只改变旁页纸叠，正文的位置、大小、倍率、页码和阅读位置均保留，不会自动执行适合整页。

桌面纸叠可以通过各自手柄自由摆放到纸张范围之外，也支持方向键和 Shift 加速，不再受旧阅读区域边界限制。手动移动整份文件时，纸叠保持与文件的相对位置；滚动正文或单独缩放 PDF 时，纸叠仍留在桌上。框内和专注模式的纸叠继续限制在各自阅读区域，和桌面位置分别记忆。「查看全部」也会包含桌面上移远的纸叠。

阅读工具默认在左侧展开：普通阅读、激光笔、荧光笔、清除、锚点、框选与输出方式，以及翻页、页码、缩放、适配和桌面整理等。目录按钮位于每份文件自身的左上角。窗口较矮时，在工具栏内滚动可找到下面的工具；不会滚动文档。状态提示暂时浮现，错误会持续显示。

## 随文件展开的目录（0.5.2）

0.5.3 起，点击文件自身左上角的目录按钮，在该文件左侧展开目录，再点收起；左侧工具栏不再放目录入口。鼠标移到文件上或选中文件即可看到按钮，直接点击另一份文件的目录按钮会选中并打开那份文件的目录。长页滚动时按钮留在可视部分，桌面缩放时维持大小；Enter / 空格可切换，Esc 收起后焦点回到本文件的按钮。

移动文件或在文件上按空格平移桌面时，目录跟随；桌面缩放后文字仍保持清晰。目录自己滚动，点击条目跳转所属文件。阅读框的目录显示在框外，专注模式为目录预留文件左侧空间，关闭后归还。

切换到其他文件、收纳 / 关闭该文件或点击空白桌面，目录自动收起，回到该文件时需再次展开。Esc 或目录右上角 × 也能收起。目录靠近窗口边缘时会调整宽度或覆盖文件的左缘，避免移出窗口；长页面滚动时保持目录可见。

桌面对象、纸张、纸叠和其中的文字禁用浏览器的文字 / 图片选择与原生拖图，Ctrl+A 不会选中整个桌面，已有桌面选区也会清除。这不影响纸张拖动、画笔与框选截图，页码输入和 OCR 输出中的文字仍可编辑、选中及复制。

## 标签收纳（0.5）

在桌面模式点击文件标签，已显示的文档会收进标签，再点一次就在原位置、大小和页码展开。带小方框标记的标签表示已收纳；收纳保留文档与阅读状态，× 或 Ctrl+W 才会关闭文件。

0.5.1 起，收纳时纸张和旁页纸叠缩向对应标签，展开时从标签回到原处。动画途中再次点击会从当前位置反向播放；支持 Windows 的减少动画偏好。首次展开尚未渲染的文件，会先完成当前页加载再展开；启动自动恢复直接呈现保存的桌面。

可以收纳全部文件，让桌面暂时空下来。收纳当前文件时，阅读工具会切换到仍展开的文件；关闭其他文件不会把已收纳的文件自动展开。在专注模式，点其他已展开文档的标签切换阅读，点当前标签可收纳。

## 每份文件的阅读框（0.5）

选中文件后，点击侧栏的阅读框图标，可以在「摊开在桌面」与「框内阅读」之间切换。纸张旁边的悬浮控件也有对应按钮，各文件可独立选择。

阅读框的文件名区域可以拖动；右下角手柄可以分别调整宽度和高度，调整框不会改变 PDF 倍率。拖框时 Esc 撤销，手柄聚焦后方向键也可调整，Shift 加大步长。正文只在框内显示，滚轮先滚动框内页面，到边界再翻页；下一页从框内上缘开始，上一页贴框内下缘。

Ctrl+滚轮只缩放指向文件的正文，框的大小和纸叠大小不变。纸叠显示在框内，仍能独立移动、调整和长按对照。收纳和重新展开阅读框，会恢复框的位置、大小及框内阅读位置；在框和散纸之间切换，分别记住各自的摆放。

## 启动与恢复（0.5）

应用菜单中的「启动与恢复」可选择是否在启动时自动打开上次文件组，默认关闭。开启后可选「恢复上次的页码与阅读位置」或「每次从第 1 页开始」。后一项只重置当前阅读页与页内位置，保留文件摆放、大小、收纳、阅读框、阅读形式、纸叠与篇幅记忆。

文件组会记住标签顺序、当前文件、收纳状态、散纸位置和宽度、阅读框位置和宽高、框内 / 专注模式阅读位置、桌面倍率与视野。每份文件的页码、专注倍率、阅读形式、锚点和纸叠属性继续由原有本地阅读记录保存。正常关闭前等待保存，临时笔迹按原规则消退，不持久化。

前后纸叠独立记住桌上的位置，正文滚动、翻页落点或 Ctrl+滚轮缩放不会带走它们。手动拖动整份文件时，纸叠随文件一起移动；拖动纸叠自己的手柄可单独调整。「整理纸张」会重新安排各文件与纸叠，桌面整体平移和缩放仍作用于所有对象。阅读框和专注模式中的纸叠固定在各自的阅读区域内。

关闭自动打开时，应用进入空桌面；上次文件组记录仍保留，之后可开启恢复。通过 PDF 文件或命令行直接启动时，优先打开明确指定的文件。部分文件缺失会提示并继续恢复其他文件，缺失记录保留供下次重试；不会搜索或移动原文件。

工作区与启动偏好存放在 WebView 本机存储的 `lightning.workspace.v1`，按单次替换保存；阅读记录仍在应用数据目录的 `reading/`。损坏或未来版本的工作区记录会保留原内容并暂停覆盖，使用默认启动设置。

## 无界桌面与专注阅读（0.3）

0.6 起，桌面采用随文件扩展的范围。平移可到当前展开文件、阅读框和纸叠的外围余量，继续拖动空白不会进入没有尽头的空桌面。文件本身可以自由搬动；按住文件拖到视野边缘，视野会继续跟随，文件到达的区域随之加入桌面。Esc 撤销本次拖动及视野跟随。「查看全部」仍能找回文件和纸叠；收进标签的文件不占当前浏览范围。

新拖入或打开的文件会放在当前视野中，并按桌面倍率选择可见大小，不再依赖第一份文件的位置。正常关闭后手动重开的文件，如果旧位置已在视野外，会移入当前视野；启动时恢复整个文件组则保留原摆放和视野，收纳标签展开也仍保留原世界位置。

OCR 输出方式、外观模式、启动恢复方式均使用与主题一致的圆角选项面板，带选中标记。方向键或 Home / End 移动选项，Enter / 空格确认，Esc 取消；点击外部也可收起。暗色模式同步使用暗色表面，窗口较小时面板会避开边缘，设置对话框中也使用相同样式。

默认进入「桌面」。每份 PDF 的当前页直接作为纸张铺在同一个桌面上，保留真实长宽比。按住纸面即可移动，也可拖上方的小文件名；纸张可以相互重叠，点击露出的部分即可置顶。右下角圆形手柄等比例缩放纸张，不会拉伸或裁掉正文。启用画笔或框选时，正文拖动用于对应工具，文件名仍可移动纸张。

纸张可以放在任意方向，包括初始位置的左侧和上方，没有固定分栏或桌面滚动条。按住空白处拖动即可平移视野；也可中键拖动，或按住空格在任意位置拖动。空白处普通滚轮与侧栏的桌面加减按钮可以缩放整个桌面。

0.4.1 起，Ctrl+滚轮只缩放鼠标指向的 PDF 正文，保持鼠标下方的内容位置；其他文件、桌面视野与前后页纸叠大小不变。连续缩放和快速移到另一份文件均按鼠标位置识别目标。Ctrl+滚轮在空白或纸叠上不缩放桌面；纸叠仍使用自己的手柄调整大小，手动放大过的纸叠也不随正文缩小而被压小。

「查看全部」自动平移、缩放以找回所有纸张；「整理纸张」重新错落叠放。「100%」恢复桌面倍率。点击上方标签也能选择被遮住的文档，并在完全离开视野时把它带回视野。

每份文档保留独立页码与前后页纸叠。纸张右侧的悬浮控件可以翻页、进入专注或关闭文件；侧栏缩放与适配按钮调整选中纸张的大小。当前选中的文档可使用锚点、临时笔迹和框选，其他文档保留其页面与纸叠。切换文件时未完成的目标页仍会在原纸张上完成显示。

0.4 起，鼠标指向哪份文件，滚轮就操作哪份文件。纸张超出可视区域时，先移动那张纸以阅读被遮住的部分；向下到页尾后再滚动才进入下一页，向上到页首后再滚动才返回上一页。下一页的上端对齐可视区域上缘，上一页的下端对齐可视区域下缘，横竖混排使用目标页真实尺寸。其他文件的位置与桌面视野保持不动；正常放得下的小纸张仍可直接滚轮翻页。Shift+滚轮或横向滚动可查看过宽纸张。

文件名聚焦后，方向键移动纸张；大小手柄聚焦后，方向键调整纸张大小。Shift 加大步长，Home 恢复默认摆放，Esc 撤销当前拖动、缩放或平移。

菜单中的「专注」进入当前文档的常规滚动阅读，继续支持放大后页内滚动、持续适配和前进页首页退页尾；返回「桌面」恢复纸张原来的摆放和大小。纸张位置、尺寸、桌面视野与倍率、工作区模式均记在本机，重开同路径文档时恢复。0.2 的旧纸张位置和宽度会自动沿用。

## 外观与背景（0.2）

左侧应用菜单中的「外观与背景」提供浅色、深色、跟随系统，以及预设主题色、颜色选择器和十六进制颜色输入。按钮、选中状态、圆角工具栏和界面色调随主题色变化，PDF 自身颜色保持不变。

可以选择本地 JPEG、PNG 或 WebP 图片作为桌面背景。图片按比例覆盖桌面；「图片不透明度」0% 完全透明，100% 完全显示。设置会实时预览，取消或 Esc 还原原外观，点击保存才持久化。

图片导入上限为 25MB，并缩小到最长边不超过 2560 像素的 JPEG 副本，随外观配置存放在 Lightning 的应用数据目录。不会改动原图，移动或删除原图后已保存的背景仍可显示。「移除图片」返回纯色桌面，「恢复默认」恢复默认浅色蓝色主题。

外观配置在 `%APPDATA%\com.lightning.pdfreader\appearance.json`，写入使用原子替换。损坏配置保留原文件并回退默认；保存失败会明确提示本次生效但未保存。

## 打开与导航

点击「打开 PDF」或按 Ctrl+O，可一次选择多份文件；也可以拖放到窗口。点击纸面选择操作目标，桌面上的标签用于收纳 / 展开，× 或 Ctrl+W 关闭当前文档。同一规范路径只打开一个标签。

← / PageUp 上一页，→ / PageDown 下一页。下一页从页首开始，上一页落在页尾。放大页面时，滚轮先在当前页内滚动，到页尾或页首后才翻页。页码框输入物理页数并回车；目录书签始终跳到目标页首，即使当前就在该页。

加减按钮或 + / - 缩放，0 或点击缩放百分比回到 100%；Ctrl+滚轮连续缩放。「适合宽度」「适合整页」会持续响应窗口尺寸变化。手动缩放后由用户控制倍率。

## 纸叠

阅读形式选择「纸叠翻页」。左上为前页，右下为后页；短按纸张翻到邻页。顶部把手移动，右下角手柄调整大小；放大后可在预览内部滚动，与主页面独立。

调到便于对照阅读的位置和大小，点击该侧「记」。之后可缩成常用小布局。按住纸张约 350ms，临时恢复记忆篇幅；松开复原，主页面不翻动。前后两侧分别记忆，记忆始终显示当前主页面的最近邻页。

把手聚焦时用方向键移动；大小手柄聚焦时用方向键缩放。Shift 增大步长，Home 恢复该侧默认布局，Esc 撤销正在拖动的调整。工具栏「重置纸叠」复位常用布局，保留阅读篇幅记忆。窗口变小只约束显示，窗口扩大后恢复保存的大小。

## 阅读锚点

在稳定显示的页面点击「设置锚点」。之后可以翻阅其他页面或切换文件；按钮显示当前文件保存的锚点。点击「返回锚点」会在当前倍率和阅读形式下恢复页码与双轴滚动比例。

锚点只保留一个，返回成功后清除；失败或被其他导航打断时保留供重试。待返回锚点会跨关闭、重开保存。普通阅读进度只恢复页码、倍率与形式，不承诺恢复所有页内位置；精确临时位置由锚点承担。

## 临时画笔

选择红色激光笔或黄色激光荧光笔，在主页面按住左键书写。按住期间整组笔迹保留。最后松开后默认停留 1.2 秒，再渐隐 0.8 秒；完全消失前继续书写会恢复整组并从最后松开重新计时。

应用菜单中的「画笔设置」可改两种笔的颜色、宽度，以及共用的停留 / 渐隐时间。设置界面显示总消失时间，提供保存、取消、恢复默认。颜色和计时为本机偏好；重启后回到普通阅读。

清除按钮仅清笔迹，保留笔种。Esc 清除并退出笔模式。翻页、缩放、切换文档会清掉笔迹，普通页内滚动保留。笔迹不会写入 PDF。

## 区域截图与 OCR

选择「截图」或「识别文字」，点「框选」或 Ctrl+G，从主 PDF 页面拖出选区。Esc 取消。截图来自原 PDF 重新渲染裁剪，不包含工具栏、纸叠和临时笔迹；截图方式不调用 OCR。

结果在右侧本地面板显示，并标明来源文件和页码。OCR 文字可编辑后复制；PNG 可复制或通过系统保存对话框另存。处理时若来源页面、文件或阅读形式变化，过时结果会丢弃。系统 OCR 需要已安装可用语言组件；不使用在线识别、Python 或模型下载。

## 保存与设置

阅读状态自动去抖保存，Ctrl+S 可立即保存；正常关闭前等待保存收尾。每份文件分别保存页码、缩放、适配方式、阅读形式、纸叠布局、阅读篇幅与锚点。

状态在 `%APPDATA%\com.lightning.pdfreader\reading`，不会在 PDF 目录创建笔记。文件移动或改名后视为新的路径身份。状态损坏或来自不支持的版本时，保留原文件、用默认值阅读并停止覆盖。写入失败在底栏提示，重试成功后才显示已保存；关闭窗口时可取消退出重试。

应用菜单中的「快捷键设置」可录入、清除与恢复默认；冲突会提示。没有默认组合的命令也列在设置中。Esc 用于取消；输入框、输入法组合和设置对话框不会触发普通阅读快捷键。按住查看篇幅的绑定在相关按键、修饰键松开或失焦时释放。
